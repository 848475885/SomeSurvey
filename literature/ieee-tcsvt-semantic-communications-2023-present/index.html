先说结论

真正显式处理离散通信错误的核心论文只有两篇。 NSTRN 直接产生 binary spike code，在 BSC 上随机翻 bit，并可按 BER 端到端训练；ResiComp 把 entropy-coded latent 分 slice 独立封包，用 mask 建模 packet erasure，并联合学习 feature-domain concealment。两者分别代表 bit flip 与 packet loss 两条路线。
连续无线 JSCC / SoftCast 谱系NOMA-UMVT 与 IRS-assisted soft video 都把 3D-DCT 系数直接映射为连续信道符号，噪声变成平滑估计误差；它们是真无线 JSCC，但不是“离散数字语义通信”。
资源感知语义 JSCCEnergy-Efficient Image Semantic Communication 把 SNR、压缩率、计算量和能耗联合优化，但正文的 binary quantization 描述与连续 AWGN/SwinJSCC 模型之间接口不完整，不能据此宣称解决 bit error。
数字源编码 ≠ 无线 JSCCSCMC、3D face descriptor、on-demand/tree bitstream、semantic/saliency scalable coding 等生成了真实数字码流，却默认可靠传输；其核心贡献是表示/压缩/任务，而非信道错误。
安全/生成方向正在增加Image Semantic Steganography 与 DRSW 分别研究秘密消息和水印；2026 的生成式 codec 利用 LLM/扩散先验。但“攻击噪声”不能自动等同 RF bit error，JSCCL 的缩写也不是 Joint Source–Channel Coding。

2023—至今的技术演进

2023
“传连续系数”与“传离散语义”首次清晰分叉。NOMA-UMVT 延续 SoftCast 的 pseudo-analog 传输；NSTRN 直接输出 binary spike 并过 BSC；SCMC 开始用 semantic/structure/signal 分层码流。
2024
机器任务和可伸缩 bitstream 成为主线。多尺度 feature compression、3DMM face descriptor 与可逆网络按需传输都在解决“只传任务需要的 bits”，但几乎不研究这些 bits 在信道中出错。
2025
资源、韧性与人机协作向系统层推进。一端是能耗感知 SwinJSCC 和 IRS soft video，另一端是 ResiComp 直接面对 packet loss；semantic/saliency scalable coding 则把机器 base layer 与人眼 enhancement layer结合。
2026
安全与 foundation/generative priors 扩展语义表示。DRSW 做双阶段水印，MTTF/JSCCL/UniCodec 用生成模型减少码率；但真实数字无线接口、soft information、HARQ/UEP 与生成真实性仍未闭环。

仍未解决好的研究空白

  • 从 entropy bitstream 到物理层的断层：大多数 codec 假设无误码；少量 JSCC 又停留在连续 AWGN latent，缺少可复现的 quantizer–modulator–decoder 接口。
  • index 几何与 bit mapping：本集合没有系统研究 VQ index 的 Gray/semantic-aware assignment、soft dequantization 或 index error 引发的 codeword 跳变。
  • 跨层不等保护：caption、base layer、descriptor 字段和树根的语义重要性不同，却普遍没有联合 UEP/HARQ。
  • 从 packet erasure 到真实 RF：ResiComp 提供了最扎实的 packet loss 基线，但仍需要 CRC、soft LLR、调制/FEC/HARQ 与 learned PLC 的联合设计。
  • 生成真实性：扩散/生成式低码率 codec 在丢包或语义 token 错误下可能产生可信但错误的内容，科学/安全场景需要不确定性与可验证性。

Introduction 的六步讲述逻辑

  1. 已有进展：通用传统/学习式图像编码已能在常规码率下改善率失真与感知质量。
  2. 仍存问题：15 kbps 水声链路要求 512×384 图像每 3 秒约 0.2 bpp；通用模型既忽略水下非高斯成像统计，也把前景和背景同等对待。
  3. 为何重要：前景物体承载科学观测信息，背景只需保持总体感知；均匀分配比特会把有限带宽浪费在非关键纹理上。
  4. 本文方案：提出 PPECN：前景用水下物理先验引导的自编码器压缩，背景由语义图和前景条件生成。
  5. 解决机制：UPG 用衰减系数与环境光调节 latent 分布；前景 latent 量化、算术编码，背景只发送廉价语义图。
  6. 核心主张：证明领域物理先验和前景/背景异构编码能在极低 bpp 下同时保住前景像素保真度与全图感知质量。

方法细节

输入先分出前景与背景。UPGAE 仅对前景图编码，并用水下成像模型的衰减系数 α、环境光 β 调整 latent；量化和算术编码产生前景比特流。背景端编码语义图，接收端 FG-BGGAN 用语义图、真实前景及 SPADE 条件合成背景，再融合输出。

数字化方案与传输开销

传输表示：两路离散表示：量化后的前景 latent 及经屏幕内容/无损方式压缩的语义图；没有 VQ codebook 或 index。

开销判断：论文以实际 bpp 报告开销。应用侧上界可复核为 15,000×3/(512×384)≈0.229 bpp；论文主要比较 0.02–0.2 bpp 区间，未公开足以还原逐层 latent 尺寸的全部参数。

\[R_{app}=\frac{15{,}000\times3}{512\times384}\approx0.229\ \mathrm{bpp}\]

信道处理机制

分类：类别 1：数字压缩后默认可靠传输

信道如何作用：水声链路只用于说明带宽约束；实验没有 AWGN、衰落、BER 或 packet loss。

decoder 实际收到：算术/语义图解码后的无误离散变量。

是否联合优化：否；训练联合优化压缩与生成，但未把通信信道放入训练。

是否真正处理 bit/index/token 错误：没有处理 bit/index 跳变。算术码任意 bit 错误可能失同步，论文未讨论。

主要结论、局限与 Codex 判断

主要结果：PPECN 在 SUIM 等数据上以相近极低 bpp 获得更好的前景 PSNR和全图感知质量，主观平均排名 1.78；物理先验也使重建分布更接近真实水下图。

局限：把信道等价为容量预算，距离无线 JSCC 仍缺 packetization、FEC、误码/丢包和端到端信道训练。

Introduction 的六步讲述逻辑

  1. 已有进展：细粒度跨模态对齐和大规模预训练已显著提高图文检索精度。
  2. 仍存问题：这些模型传输浮点特征，落地时仍需量化与独立信道编码；低带宽和信道噪声下精度出现 cliff effect。
  3. 为何重要：终端—云检索需要频繁上送视觉/文本特征，带宽与错误鲁棒性直接决定任务可用性。
  4. 本文方案：提出 NSTRN，用脉冲激活发送器产生紧凑二进制 spike code，循环接收器与跨模态推理网络完成检索。
